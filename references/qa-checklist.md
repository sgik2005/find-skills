# PPTX 최종 검수 체크리스트

## 파일과 원본

- [ ] 승인된 경로와 파일명에 새 PPTX가 저장되었다.
- [ ] 같은 이름의 기존 파일을 승인 없이 덮어쓰지 않았다.
- [ ] 원본 자료의 내용, 해시 또는 수정 시각이 바뀌지 않았다.
- [ ] 최종 폴더에 불필요한 임시·검사용 파일이 남지 않았다.

## 구조와 내용

- [ ] 슬라이드 수와 순서가 승인된 계획과 맞는다.
- [ ] 화면 비율이 요청값과 맞으며, 기본안이면 16:9이다.
- [ ] 각 슬라이드는 핵심 메시지 하나에 집중한다.
- [ ] 사실, 수치, 용어와 출처가 입력 자료의 범위를 벗어나지 않는다.
- [ ] 불명확한 사실·수치·쪽수는 `확인 필요`로 표시했다.

## 디자인과 편집성

- [ ] 디자인 문서의 색상, 여백, 간격, 구성 원칙을 적용했다.
- [ ] 제목·본문 크기가 승인된 최소값을 충족한다.
- [ ] 요청 글꼴 또는 승인된 대체 글꼴이 실제 파일에 기록되어 있다.
- [ ] 표, 차트, 흐름도, 활동 요소가 가능한 한 편집 가능한 객체다.
- [ ] 근거 없는 정량 차트나 장식용 수치를 만들지 않았다.

## 발표자 노트와 출처

- [ ] 모든 슬라이드에 노트가 있다.
- [ ] 각 노트에는 `발표 스크립트`, `교사 발문`, `[Sources]`만 있다.
- [ ] 발표 스크립트는 3~5문장이고 화면 문구의 단순 복사가 아니다.
- [ ] 교사 발문은 1~2개다.
- [ ] 출처가 없으면 `[Sources] 해당 없음`으로 적었다.

## 렌더링

- [ ] 전체 슬라이드를 렌더링했다.
- [ ] 각 슬라이드를 개별 확인했다.
- [ ] 글자·도형·이미지의 잘림과 겹침이 없다.
- [ ] 텍스트 상자 오버플로와 부자연스러운 줄바꿈이 없다.
- [ ] 색 대비와 읽기 순서가 수업·발표 환경에 적절하다.
- [ ] 렌더링 실패나 환경 차이는 `확인 필요`로 보고했다.

## 완료 보고

- [ ] 실제 최종 저장 경로를 제시했다.
- [ ] 생성 파일과 검수 결과를 표로 정리했다.
- [ ] 글꼴 대체, 편집성 제한, 외부 환경 차이 등 남은 확인 사항을 밝혔다.
